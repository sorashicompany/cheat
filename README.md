# Clicker Lab

Небольшое статическое приложение для локального анализа JSON-ответов и HAR-файлов clicker API.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages в настройках репозитория (ветка `main`, папка `/ (root)`).

## Возможности
- Разбор JSON-ответов, массивов ответов и HAR JSON.
- Сводка по balance, counted, earned, pending.
- Подсчёт суммарного earned и изменение баланса между первым и последним найденными ответами.
- Выделение HTTP 429 и ответов `slow`.

## Конфиденциальность
Всё обрабатывается в браузере: приложение не использует сеть, не загружает данные на сервер и не просит логин/пароль. HAR-файлы могут содержать cookies и токены — не публикуйте их.

Это диагностический инструмент, а не чит: он не подменяет серверные начисления и не обходит ограничения.
